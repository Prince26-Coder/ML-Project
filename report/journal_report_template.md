## 4. Methodology

### 4.1 K-means
K-means partitions latitude/longitude observations into a chosen number of groups by minimising within-cluster squared Euclidean distances. It is used here as a baseline; because the Earth is curved, its distance assumptions are an approximation for geographic coordinates.

### 4.2 Hierarchical clustering with haversine distance
K-means uses standardised latitude, longitude, depth and magnitude. Hierarchical clustering uses the haversine distance between epicentres and therefore groups by geographic proximity; depth and magnitude are retained for interpreting cluster properties. The Silhouette scores use different feature/distance definitions for the two methods and must be compared cautiously. For computational reasons, the code may evaluate a sample for hierarchical clustering; report the exact sample size.

### 4.3 Cluster evaluation
The Silhouette score measures how much each observation resembles its own cluster compared with other clusters. Scores range from -1 to 1; higher values generally indicate better-separated clusters. It is not a measure of seismic hazard or prediction accuracy.

### 4.4 Gutenberg–Richter magnitude-frequency regression
The cumulative number of events with magnitude at least M is calculated for a sequence of magnitude thresholds. A linear regression is fitted to `log10(N(M >= m))` versus magnitude:

`log10(N) = a - bM`

Report the fitted slope, intercept, selected magnitude range, number of events used and R². The estimated relationship can be affected by catalogue completeness and the chosen time window.
